# 萌萌记账 · 本地前端

## 启动

在本目录运行 `npm start`（需已安装 Node.js，无需安装依赖），然后打开 http://127.0.0.1:8765/ 。按 Ctrl+C 停止。仅监听本机，不部署。

请固定使用同一地址、端口和浏览器。localhost 与 127.0.0.1 是不同的存储来源；改变端口也不会共享账本。不要直接双击 HTML 作为日常运行方式。

## 目录与页面

- `index.html`：默认进入首页
- `dashboard.html`：首页概览、快捷记账、预算及趋势
- `analytics.html`：统计分析、分类金额、每日支出
- `login.html`：欢迎与本地进入入口（无云登录、无密码保护）
- `transactions.html`：明细筛选、编辑删除、筛选范围 CSV
- `entry.html`：新增与编辑，保存返回来源页面
- `settings.html`：月度预算、JSON 备份恢复、分类、隐私说明
- `assets/app.css`：共享粉色主题及响应式样式
- `assets/app.js`：共享导航、页面渲染、表单和交互
- `assets/store.js`：IndexedDB、校验、整数分计算、CSV 转义
- `server.js`：无依赖本地静态服务
- `_1`～`_5`：原始 Stitch `code.html` 与 `screen.png`，原样保留，不作为应用入口

原型映射：_1 → dashboard，_2 → analytics，_3 → login，_4 → transactions，_5 → entry。新增 settings。

## 行为与范围

按 PRD V1.1 实现首版核心功能。首次使用为空账本；全部金额使用整数分保存。日期采用本地日历；未来日期、零负金额、三位小数被拒绝。保存失败保留输入，删除和整库导入均需确认。离开未保存表单会提示。

保留 Stitch 的白色侧栏、浅粉背景、玫瑰粉按钮、圆角卡片及主要内容分栏，提取为无 CDN 依赖的共享样式；为真实数据和手机屏幕调整了部分细节、图标与排布，并非逐像素复刻。

首页、明细与统计共享所选月份。明细按日倒序、同日按创建时间倒序；每批 50 条。CSV 仅导出当前筛选结果，带 UTF-8 BOM 并转义公式前缀、引号、换行。JSON 包含版本、分类、预算及全部记录，校验通过且确认后在一个 IndexedDB 事务内替换；导入摘要提供当前账本备份按钮。

清除浏览器数据可能丢失账本，请定期导出 JSON。数据不上传服务器；本地数据库并未加密。不包含云同步、账户、支付、PDF/Excel 月报、自定义分类或记账模板等后续功能。

## 验证

`npm run check` 检查脚本语法。浏览器回归记录与限制见 `VALIDATION.md`。

自动浏览器回归：安装 Chrome，执行 `npm install` 后运行 `npm test`。测试使用独立的临时浏览器会话，测试服务端口为 8788，不使用日常浏览器数据；截图与结果写入 `tests/artifacts/`。开发服务 `npm start` 本身不依赖这些测试包。
