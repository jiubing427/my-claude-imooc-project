Chrome 无界面真实浏览器测试，使用独立测试会话，不向日常浏览器账本写入测试数据。

自动回归 42 项通过，另外 8 项预算、日期归属与浏览器重开检查通过；无未捕获浏览器脚本错误。六个页面在 360px 下无横向溢出，手机顶部按钮与导航选中样式已另行复核。

| 场景 | 结果 |
| --- | --- |
| 新增 25.50 元支出、5,000 元收入 | 通过；首页、明细与预算联动 |

| 合法备份、损坏文件、取消导入 | 通过；失败与取消保持原数据 |

| 手机与桌面布局 | 已检查截图；360px 无横向溢出 |

存储故障测试发现并修复了事务错误对象为空时不能显示失败提示的问题。性能优化缓存所选月份排序结果，数据或月份变化时自动失效，减少筛选时的重复计算。

### 一万笔记录复测

| 操作 | 实测 |
| --- | --- |
| 首页载入并出现表单 | 245 ms |
| 明细载入并出现记录 | 208 ms |

脚本语法检查通过。运行自动回归需安装 Chrome，执行 `npm install` 后运行 `npm test`；测试包仅用于开发测试。

尚未进行其他浏览器、真实手机、屏幕阅读器及完整颜色对比度审计。未部署、未接入云服务。
