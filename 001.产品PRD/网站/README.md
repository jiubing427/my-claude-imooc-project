# 花花账本

根据《个人财务管理产品PRD V1.1》开发的粉色个人记账网站。使用原生 HTML、CSS、JavaScript 和 IndexedDB，无第三方运行依赖。

## 本地启动

安装 Node.js 后，双击“启动花花账本.cmd”，在浏览器打开 http://127.0.0.1:4173 。保持启动窗口运行；关闭窗口即可停止服务。也可以在此目录运行 `npm start`。

请始终使用同一个浏览器和同一个访问地址。直接双击 dist/index.html 不能可靠加载 ES 模块，请通过启动脚本访问。

## 功能

- 收入、支出新增、编辑、删除，按月、类型、分类和备注筛选。
- 月度预算、80% 提示、超支提醒、当日支出和月度汇总。
- 分类占比、每日趋势、文字明细，空账本引导和手机导航。
- JSON 完整备份及原子恢复，CSV 按当前筛选导出。
- 数据仅存于当前浏览器；无账户、云同步或银行连接。清理浏览器数据前请备份。本地版和线上版为不同地址，数据不互通，可用 JSON 迁移。

## 开发与检查

`npm test` 运行核心规则测试。`dist/` 为网站文件；`server.mjs` 为仅监听本机的静态服务。测试数据不会写入交付版账本。

首版不包含 PRD 中 P1 的自定义分类和常用模板；备注搜索已实现。没有 Service Worker 或安装型离线缓存。
